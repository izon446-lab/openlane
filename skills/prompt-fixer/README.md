# Prompt Fixer

Load this skill when the user's message is messy, scattered, typo-heavy, mixed-language, stream-of-consciousness, or unclear — or when they explicitly ask to fix, improve, rewrite, or structure a prompt ("prompt düzelt", "bunu düzgün yaz"). Interprets vague intent, fills gaps with sensible defaults, runs an advisor critique pass on the corrected prompt, and either shows the clean structured prompt or silently executes the task. On first load, read references/interpretation-rules.md. Worked examples in examples/demo-run.md.
