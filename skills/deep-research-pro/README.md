# Deep Research Pro

Load this skill for thorough, Perplexity-level deep research. Triggers on requests for thorough investigation, source-backed briefs, market or technical landscape analysis, evidence-based comparisons, fact-checking, "araştır", "deep research", "rapor hazırla", or when the user wants a polished research report with citations. Handles advisor-critiqued research planning, iterative multi-angle search, source credibility scoring, conflicting evidence resolution, and structured report output. On first load, read references/workflow.md, references/source-standards.md and references/report-templates.md. For a full worked example, read examples/demo-run.md.
