# Repro checklist

- [ ] Single failing claim
- [ ] Exact package/runtime versions or "unknown"
- [ ] Checkout pin (tag or SHA) when relevant
- [ ] ≤10 steps, each a command or one UI action
- [ ] Expected and actual are concrete (status code, stderr line, screenshot path)
- [ ] Fixture is minimal (one file or <30 lines)
- [ ] Works on a clean machine (no "open my IDE")
